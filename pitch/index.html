Our insight
Mask first.
Analyze second.

Privacy is step 1 of the pipeline, not a final check. Raw PII never crosses a service boundary, never reaches the LLM, never lands in the database — by architecture, not by promise.

How it works · Click any stage

One Python boundary. Five stages. Raw PII dies at stage 2.

01 · DETECT
PII Scan
Regex + Presidio NER + German rules + hard negatives
02 · MASK
Anonymize
Stable [NAME_1], [EMAIL_1] placeholders
03 · GATE
Safety Gate
Second PII scan on masked text — blocks if any leak
04 · LLM
Analyze
Stub or OpenAI — only masked text leaves the box
05 · VALIDATE
Final Scrub
Output re-scanned + JSON validated before storage
What gets stored: masked message + PII metadata (type, offset — no entity_value column) + analysis + a SHA-256 of the raw input. That's it.

Why this is hard · Our moat

Anyone can call an LLM. Almost nobody gets the masking layer right.

Detection layers
