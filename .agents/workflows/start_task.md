# Workflow: start_task

1. Read `AGENTS.md`.
2. Read `docs/PROJECT_CONTEXT.md`.
3. Read `docs/AI_HANDOFF.md` — this is the baton.
4. Skim `docs/DECISIONS.md`, `docs/OPEN_TASKS.md`, `docs/ERRORS_AND_FIXES.md`.
5. Run `git status` / `git diff` (if git is initialized) to see uncommitted work.
6. Restate the current task in your own words and confirm it against the handoff.
7. **Continue from "Next Recommended Steps"** in `docs/AI_HANDOFF.md`. Do not
   restart from zero or duplicate work already marked Done in
   `docs/OPEN_TASKS.md`.

Use the `repo_context` skill if you need deeper understanding first.
